## Documentación de la API

La API está documentada con OpenAPI 3 en [openapi.yaml](openapi.yaml). Con el servidor levantado,
la documentación interactiva (Swagger UI) está en `http://localhost:3000/api/docs`: ahí se ven todos
los endpoints con sus parámetros, el body esperado, las respuestas posibles y el rol requerido, y se
pueden probar desde el navegador.
